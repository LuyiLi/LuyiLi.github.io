# Li Hongyi — Personal Homepage

Academic homepage featuring research on robot learning, perceptive locomotion, and whole-body control.

## Structure

- `index.html`: page content and main layout.
- `assets/`: local scripts, styles, research figures, and citation data.
- `.nojekyll`: serves the site as static files on GitHub Pages.

## Publishing

GitHub Pages should publish the root directory of the `main` branch. Pushing updates to `main` then updates the website automatically.

## Editing

Edit `index.html` to update the introduction, research, experience, or contact information. Keep relative asset paths so the page works both locally and on GitHub Pages.
